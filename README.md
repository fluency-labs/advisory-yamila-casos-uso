# advisory-yamila-casos-uso

Diagrama interactivo de priorización de casos de uso para Pure (Yamila Ale), Sesión 2 del Practical AI Advisory.

Vive en: https://fluency-labs.github.io/advisory-yamila-casos-uso/

## Cómo usarlo

- Click sobre cada item según el orden en el que quieras abordarlo
- Drag-and-drop en el sidebar para reordenar la priorización
- Exportar el resultado como Markdown o JSON al clipboard
- Persistencia local con `localStorage` (sobrevive recargas de página)

Patrón replicado del diagrama Retail Upselling (Douglas, S4).
